# HIROKA AMANO — Portfolio (MVP)

Red Noir Editorial デザインの個人ポートフォリオサイト。Next.js App Router + TypeScript + Tailwind CSS。

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開く。

## ビルド

```bash
npm run build
npm start
```

## Vercel

リポジトリを Vercel に接続し、Framework Preset を **Next.js** のままデプロイ。
